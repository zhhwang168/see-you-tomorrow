Oh, I see. In space, astronauts float because they're in freefall, like a gentle drop through space, so gravity pulls them, but they're not touching anything to feel it. It's like being in a falling elevator where everything floats together. So yes, gravity is there, but they feel weightless because they're falling freely. Once upon a time there was a little rabbit named Pip who couldn't fall asleep because the world was too bright and busy. So he climbed up to the tallest hill and looked down at the friendly moon who gently blinked and said, it's okay Pip just breathe one slow breath at a time. Your next experiment.

The website shows the demo. Qwen and the speech models run in the Windows app on your own machine.

Download the Windows projectView source on GitHub

First setup downloads the tools and models. Hands-free voice works best in supported Chrome versions.

  1. Download & extract

    Unzip the project into a folder on your computer.

  2. Run Setup See You Tomorrow.cmd

    The setup prepares the tools. Allow time and disk space for model downloads.

  3. Start a conversation

    Keep the server window open. Type first, then try the microphone and voices.
